# AERION AI 🚀

### One workspace. More ways to think, learn, and create.

**AERION AI** is an AI workspace I'm building to bring useful AI-powered tools into one place. The goal is to create a modern, accessible experience that helps people learn, explore ideas, and get work done.

> **Status:** In development · Preparing for launch

## ✨ Features

- 💬 **AI Chat** — Assistance with questions, ideas, and everyday tasks.
- 📚 **Study Mode** — A learning-focused experience for understanding topics.
- 👁️ **Vision Mode** — Image-based questions and visual understanding.
- 🎙️ **Voice Interaction** — Voice input and text-to-speech where supported.
- 🌐 **Web Search** — Web-assisted answers and source information where available.
- 🗂️ **Chat History** — Keep conversations organized.
- 🔐 **User Accounts** — Sign-in and account features.

*Features and availability may change as development continues.*

## 🛠️ Built With

- React
- TypeScript
- Vite
- Supabase
- AI service/API integrations

AERION connects to existing AI services. The project focuses on building a useful workspace around these capabilities.
